# Contributing

Thanks for taking an interest in the Unknown Shores archive.

This repository preserves selected **historical and reference material**. It is not the live canon-authoring surface.

## Good contributions

Useful contributions include:

- fixing a broken repository link or reference;
- documenting reproducible problems with an archived file;
- correcting clear repository documentation errors;
- supplying historical context when the source and relationship are known;
- improving accessibility or clarity without changing the meaning of preserved historical material.

## Please do not submit

- new Unknown Shores canon or lore by pull request;
- private or unreleased source material;
- purchased books, commercial RPG PDFs, or other copyrighted third-party archives;
- credentials, tokens, private contact information, or personal records;
- generated rewrites presented as historical originals.

Current Unknown Shores lore is maintained through the live World Anvil world, not this repository.

## Historical corrections

When proposing a historical correction, please include enough context to explain **what is being corrected and why**. Dates, original filenames, commit links, screenshots of your own material, or other provenance can help.

A historical file that is awkward, obsolete, or factually different from current canon may still be intentionally preserved because it documents the project's development.

## Pull requests

Keep pull requests small and focused. Do not combine unrelated cleanup with a historical-content change.

If you are unsure whether something belongs here, open an issue before uploading material.
