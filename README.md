# Unknown Shores

**Unknown Shores** is an original fantasy campaign setting created by Brian Laliberte and developed over more than three decades.

This repository is a **public historical archive and reference surface** for selected Unknown Shores material, including older theme work, CSS, BBCode, experiments, and backups that may still be useful for comparison or recovery.

## Start here

- **Official site:** https://www.unknownshoresrpg.com
- **Living world and current canon:** https://www.worldanvil.com/w/unknownshoresrpg
- **Support the project:** https://ko-fi.com/unknownshores

## Important authority note

This repository is **not** the live canon authority and is **not** the production deployment source.

World Anvil is the current authority for published Unknown Shores lore. Material preserved here may be historical, superseded, experimental, or retained purely because it helps reconstruct how the project evolved.

If this repository and the live World Anvil world disagree, treat the live World Anvil material as current unless a newer explicit project record says otherwise.

## What you may find here

Depending on the period represented by a file or commit, this repository may contain:

- historical World Anvil CSS and theme experiments
- BBCode and presentation snippets
- prior working copies and backup material
- layout tests and visual experiments
- reference material useful for restoration or comparison

A filename containing words such as `final`, `working`, or `backup` is historical evidence, not automatic proof that the file is the current production version.

## Project links

Unknown Shores continues to be developed as a living setting, with current lore, articles, maps, histories, cultures, characters, and campaign material published through the official site and World Anvil.

If you are here to **explore the setting rather than the repository history**, the official site is the better front door.
