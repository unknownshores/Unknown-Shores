# Support

For the current Unknown Shores setting and published lore, start with:

- https://www.unknownshoresrpg.com
- https://www.worldanvil.com/w/unknownshoresrpg

For repository-specific problems such as a broken archived file, missing historical context, or a reproducible issue with material stored here, open a GitHub issue in this repository.

Please do not treat this repository as the current canon source. Historical files may intentionally differ from the live World Anvil setting.
